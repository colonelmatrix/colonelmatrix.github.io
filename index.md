# Barad-dur Photos

Barad-dur Photos is a personal photo-management setup maintained by [colonelmatrix](https://github.com/colonelmatrix).

It uses rclone to connect the owner’s Google Drive storage to a privately operated Immich installation for importing, organising and reviewing duplicate photos. Adobe Lightroom Classic is used for editing.

This application is for the owner’s personal use. This website contains information about the setup; it does not provide access to the photo library.
